# NOTICE

## Projeto Clima

Este projeto utiliza serviços e recursos de terceiros para obter e apresentar
informações meteorológicas.

### Open-Meteo

A aplicação utiliza a API pública Open-Meteo para consulta de dados
meteorológicos e geocodificação de cidades.

Site oficial: https://open-meteo.com/

A utilização dos dados deve respeitar os termos e condições disponibilizados
pelo serviço.

### Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Jest
- Open-Meteo API
